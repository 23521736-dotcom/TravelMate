## 2. CÁC THAY ĐỔI CẤU TRÚC CHÍNH (ENTERPRISE STANDARDS)

### A. Triển khai Clean Architecture (3 Lớp)
Dự án đã được chia thành các package chuyên biệt:
1.  **domain/** (Pure Kotlin):
    *   `model/`: Chứa các entity thực thể (Trip, User, Expense).
    *   `repository/`: Các interface định nghĩa hành vi dữ liệu.
    *   `usecase/`: Các logic nghiệp vụ đơn lẻ (ví dụ: `LoginUseCase`).
2.  **data/** (Framework specific):
    *   `repository/`: Triển khai các interface từ Domain (sử dụng Firebase SDK).
    *   `mapper/`: Chuyển đổi giữa Data DTO và Domain Model.
3.  **ui/** (Jetpack Compose):
    *   `viewmodel/`: Xử lý logic và giữ trạng thái cho UI.
    *   `state/`: Định nghĩa các Sealed class/Data class cho UI State.
    *   `navigation/`: Quản lý luồng chuyển màn hình tập trung.
    *   `theme/`: Hệ thống Design System (Material3).

### B. Nâng cấp Công nghệ & Công cụ (Tech Stack)
*   **Hilt (Dependency Injection):** Đã cấu hình để tự động tiêm các dependencies (FirebaseAuth, Repository, ViewModels).
*   **KSP (Kotlin Symbol Processing):** Thay thế Kapt để tăng tốc độ biên dịch (Compatible with AGP 9.2+).
*   **Kotlin Serialization:** Dùng để xử lý dữ liệu JSON chuẩn doanh nghiệp.
*   **Material3:** Hoàn thiện `Theme.kt` và `Type.kt` để quản lý giao diện tập trung.
